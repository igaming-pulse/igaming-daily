## 二、核心機制欄怎麼寫

- 寫「借鑑哪個原型＋第幾代／哪個版本」：`Super Ace II`、`Fortune Gems 500`、`Pinata Wins`、`Gates of Olympus Super Scatter`
- 他廠仿作：`Fortune Gems 系（仿 Fortune Gems 3）` 這類寫法也可以
- 看得出是哪個原型、但查不到是仿哪一代：寫 `Super Ace 系（代數未確認）`，**不要猜**
- 沒有借鑑表上任何原型：寫 `-`
- 一律要有來源依據（官網遊戲頁、SlotCatalog、評測），查不到就寫「未確認」

## 三、微創新欄怎麼寫

- 10～30 個字，**只寫核心玩法相對原型多了或改了什麼，聚焦 Base Game**；不是功能清單（那是「關鍵特色」）
- 判定為換皮：寫 `無（換皮）`
- 沒有原型（第二級）：寫 Base Game 的新玩法本身

### BP 的判斷標準

**算創新**
- 功能更豐富的金框（保留、擴展、成為倍數加成）
- 可累積的倍數（在連續消除及整輪中延續，不重置）
- 在熟悉循環上疊加新層（獎池檔位、收集進度條、轉盤或選擇環節）
- 下限與上限升級版（1000 系列、Super Scatter 式的區間升級）
- 專屬於題材的機制（只在該題材世界中才成立的玩法）

**不算創新**：新的配色方案、同一賠付表下更換新符號、更快的動畫速度、多加一個分散符號

**BP 範例**：Bathala 1000（BP 簡報的本地化案例）基於 Fortune Gems，保留 3x3＋五線＋倍數軸；Extra Bet 移除 1x、2x，Ex Nudge 推進收集倍數至 1,000x，旋轉前隨機特色（Split／Nudge／Wild Gems），四級獎池；最高贏分 375x → 30,000x。

**BP 的菲律賓重點**：Base Game 要有清楚的視覺焦點與即時回饋；【金框＋Base Game 反饋＋Multiplier】是關鍵元素，【Buy Feature＋Extra Bet】是必備功能。

## 四、三級分法（🎰 區依序排列）

| 級別 | 條件 | 呈現 |
|---|---|---|
| **第一級 N+1** | 有主流原型，而且創新在 Base Game 就看得到 | 排最前面，完整卡片 |
| **第二級 原創機制** | 沒有主流原型，但 Base Game 有新玩法 | 排第二，完整卡片 |
| **第三級 換皮／資料不足** | 只換主題或配色；或創新只在 Free Game 裡；或參數未公布、無法判斷 | 區塊最後，精簡卡片（小圖＋核心機制＋判定＋三個參數＋一句話） |

- 創新只出現在 Free Game、Base Game 看不出差異 → 降一級（第一、二級都降到第三級）
- 第一級不夠多就照實呈現，**不拿第三級補完整卡片**
